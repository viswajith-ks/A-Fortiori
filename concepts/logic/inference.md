# Inference

**Category:** logic

## Definition
Inference is the process of drawing conclusions from premises using reasoning, the building block of all argument.

## Types
- **Deductive inference:** Guarantees the conclusion if premises are true ([Deduction](deduction.md)).
- **Inductive inference:** Renders the conclusion probable ([Induction](../epistemology/induction.md)).
- **Abductive inference:** Suggests the most plausible explanation.

## Structure
- Premises → Reasoning Process → Conclusion

## Rules
- Must follow [validity](validity.md) criteria for deductive inference.
- Inductive inference typically relies on pattern or statistical support.
