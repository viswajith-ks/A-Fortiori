# Paraconsistent Logic

**Category:** logic

## Definition
Paraconsistent logic is any logical system that rejects the [principle of explosion](principle-of-explosion.md), allowing some contradictions to exist without making every statement provable.

## Description
While classical logic says that any contradiction makes everything true, paraconsistent systems can handle contradictions in a controlled way. This doesn't mean "anything goes"—these systems maintain rigorous standards while being more tolerant of certain inconsistencies.

## Motivation
- Real-world databases often contain contradictory information
- Scientific theories may have inconsistent elements during development
- Legal systems can contain conflicting laws
- Philosophical paradoxes may require contradictory truths

## Key Features
- **Controlled Explosion**: Contradictions don't spread to unrelated areas
- **Relevance**: Only relevant contradictions affect related statements
- **Gradual Inconsistency**: Some parts can be inconsistent while others remain classical

## Major Systems
- **LP (Logic of Paradox)**: Allows three truth values: true, false, both
- **Relevant Logic**: Connections must be "relevant" to the conclusion
- **Adaptive Logic**: Classical reasoning unless contradictions are encountered

## Philosophical Implications
Challenges the [Law of Non-Contradiction](classical-logical-axioms.md) as absolutely necessary. Suggests reality itself might contain genuine contradictions.

## Applications
- **Computer Science**: Handling inconsistent databases
- **Artificial Intelligence**: Reasoning with conflicting information
- **Philosophy**: Addressing paradoxes like the Liar Paradox

## Criticisms
- May allow too much irrationality
- Unclear when contradictions should be accepted
- Complex technical apparatus for uncertain gains
